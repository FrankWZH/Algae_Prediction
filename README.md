# 📖 Overview

Algae Prediction System is a machine learning-based environmental monitoring project designed to analyze water quality data and predict algae growth trends.

This platform aims to assist:

- 🌱 Environmental researchers
- 💧 Water resource management teams
- 🌍 Ecological monitoring organizations
- 🎓 Academic research projects

by providing intelligent prediction and analysis tools for harmful algae bloom detection and water quality monitoring.

## 🔍 Core Functionalities

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/FrankWZH/Algae_Prediction.git
```

## 2️⃣ Enter the Project Directory

```bash
cd Algae_Prediction
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🚀 Running the Project

## Run the Main Application

```bash
python main.py
```

## Or Launch Jupyter Notebook

```bash
jupyter notebook
```
